
                P i e t y
                =========
                
This is the Piety desktop, a self-contained 
computing environment running in a single
interactive Python session. Here you can
compose documents, create and run Python code,
browse internet web pages, and access the host
computer file system, all without resorting to a 
graphical desktop with multiple windows. 

Almost everything you see on the desktop
can be edited. Most of the desktop shows two
large panels that contain editor windows. The
panel on the left can hold one or two editor
windows. The panel on the right can
only show one window, the viewer window.
You can edit in the viewer window as well, but
it usually displays reference information.
There are commands to populate the viewer with
lists of directories or editing buffers, help
text, shell command output, and documentation
like this file you are reading now.

The lower part of the desktop shows the Python
interpreter, where you can type Python statements
amd display their output.

Most navigating within and among windows is 
done by typing familiar (to some) Emacs keycodes.

To scroll down by a screenful, type C-v
(control-V, hold down the ctrl key and press
the v key). Try it now!

To scroll up, type M-v (meta-V, hold down the
alt key and press the v key). To go to the top
of the buffer, type M-< (hold down the alt key
and the shift key and press the < key) and to
go to the bottom type M->.

To switch from the viewer window to an editor
window, type C-x o (Type C-x, then release the
control key and type o for "other window"). To
go back to the viewer window, type C-x v
("viewer window")

To switch from editing (or viewing) in a window
to using the Python interpreter, type M-x. Now
you can type Python statements at the usual
>>> prompt and view the output. To return to
the same editor window, type the Python
statement pm() (that is, call the pm function
with no arguments).
