 
                Piety Keys
                ==========
                    
This is a list of key sequences (usually just
called keys) used in the Piety desktop and
Piety editors.

C-v, control v, means hold down the CTRL key
     and press the v key.
     
M-v, meta v, means hold down the ALT key and 
     press the v key.

Many (but not all) keys used by Piety behave
like the same keys in the Emacs editor.

Scrolling

C-v  Scroll down
M-v  Scroll up
M-<  Move to the top of the buffer
M->  Move to the bottom of the buffer 
C-n  next line, move down one line
     (or use the down arrow key)
C-p  previous line, move up one line
     (or use the up arrow key)

Scrolling viewer window while
working in an editor window

C-t  Scroll viewer down
M-t  Scroll viewer up
M-(  Move to top of buffer in viewer
M-)  Move to bottom of buffer in viewer
M-n  Move down to next line in viewer
M-p  Move up to previous line in viewer

Effects of M-n and M-p are not visible
until you switch to viewer window
 
Search and replace

C-s  Search forward
C-r  Search backward

M-%  Replace
  
Buffers

C-x C-b   List buffers, except web pages
C-x b     Switch to buffer
C-x k     Delete current buffer            

C-o  Open buffer named on this viewer line
     in viewer window
M-o  Open buffer named on this viewer line
     in editor window

Windows

C-x 2  Split one editor window into two
C-x 1  Delete the other editor window
C-x o  Move cursor to other editor window

C-x v  Move cursor from editor to viewer       
C-x o  Move cursor from viewer to editor
     
Directories

C-x d  List directory
C-o  List directory named on this viewer line
     
Files

C-x C-f  Open or create file in new buffer
C-o      Open file named on this viewer line
         in viewer window
M-o      Open file named on this viewer line
         in editor window
         
C-x C-s  Save file, with same file name
C-x C-w  Save file, prompt for file name

Cursor motion

C-f  Forward character (or use right arrow)
C-b  Backward character (or use left arrow)
C-a  Beginning of line
C-e  End of line
M-f  Forward word
M-b  Backward word
C-n  Next line (or use down arrow)
C-p  Previous line (or use up arrow)
C-v  Scroll down
M-v  Scroll up
M-<  Top of buffer
M->  End of buffer
C-s  Forward to search string
C-r  Backward to search string

Define multiline region for delete and format 

C-SPACE Set mark at current line to define one
        end of region. Move cusor to any other 
        line to define the other end. 
        Region includes lines at both ends.
C-@     Set mark at current line, like C-SPACE
      
Delete, cut and paste

BACKSPACE Delete character before cursor
C-h  Delete character before cursor
C-d  Delete character under cursor

M-d  Delete word, save in paste buffer
     Successive M-d collect words in paste buffer.
C-k  Delete to end of line,  save in paste buffer.
     Successive C-k collect multiple lines 
     in paste buffer.
C-u  Delete to start of line, save in paste buffer.

C-w  Delete the entire region and save all lines
     in the paste buffer.
 
C-y  Paste ('yank') words from paste buffer
     into current line at cursor.
     -- OR --
     If paste buffer contains multiple lines
     from C-w or multiple C-k, paste ('yank')
     all lines from paste buffer before current 
     line. 
     Paste buffer contents can be pasted 
     multiple times to make copies.
     
Formatting

M-q  Fill (wrap) lines in region
M-^  Join lines in region into one
C-c >  Indent region
C-c <  Outdent region

If no region is defined, formatting commands
apply only to the current line.

Refresh

C-l  Refresh current editing window
M-l  Refresh both editing windows
M-m  Refresh viewer window
     works when cursor in editor window

Append mode - like on a printing terminal,
just keep typing, no going back or editing

C-x C-a  Enter append mode
.        Exit append mode 
         (. only at beginning of line)
         
Web browsing         

C-x C-w   List web pages (.htxt buffers)

C-o  Open URL named on this viewer line
     in viewer window
M-o  Open URL named on this viewer line
     in editor window

C-o  Open URL referenced by next footnote
     on this viewer line in viewer window
M-o  Open URL referenced by next footnote
     on this viewer line in editor window

C-o  When on first line of web page buffer
     with page URL, reload this web page.

C-x C-l  Reload web page shown in current 
         buffer, needn't be on first line.

                 
Python

M-x  Move cursor from window to Python REPL
ve() Move cursor from REPL back to window
     pm() does the same thing, appears in 
     older Piety documentation

M-y  Enter and run a single Python command 
     then return to window

C-p  Retrieve previous command in history
     repeat to retrieve older commands
C-n  Retrieve next command in history
     use after C-p commands.
          
C-x C-r  Write module to file and reload
