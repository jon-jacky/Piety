
                Piety Keys
                ==========
                    
This is a list of key sequences (usually just
called keys) used in the Piety desktop and
Piety editors.

C-v, control v, means hold down the CTRL key
     and press the v key.
     
M-v, meta v, means hold down the ALT key and 
     press the v key.

Many (but not all) keys used by Piety behave
like the same keys in the Emacs editor.

Scrolling

C-v  Scroll down
M-v  Scroll up
M-<  Move to the top of the buffer
M->  Move to the bottom of the buffer 
C-n  next line, move down one line
     (or use the down arrow key)
C-p  previous line, move up one line
     (or use the up arrow key)

Scrolling viewer window while
working in an editor window

C-t  Scroll viewer down
M-t  Scroll viewer up
M-(  Move to top of buffer in viewer
M-)  Move to bottom of buffer in viewer
 
Search and replace

C-s  Search forward
C-r  Search backward

M-%  Replace
  
Buffers

C-x C-b   List buffers
C-x b     Switch to buffer
C-x k     Delete current buffer            

C-o  Open buffer named on viewer line
     in viewer window
M-o  Open buffer named on viewer line
     in editor window

Windows

C-x 2  Split one editor window into two
C-x 1  Delete the other editor window
C-x o  Move cursor to other editor window

C-x v  Move cursor from editor to viewer       
C-x o  Move cursor from viewer to editor
     
Directories

C-x d  List directory
C-o  List directory named on viewer line
     
Files

C-x C-f  Open or create file in new buffer
C-o      Open file named on viewer line

C-x C-s  Save file, with same file name
C-x C-w  Save file, prompt for file name

Cursor motion

C-f  Forward character (or use right arrow)
C-b  Backward character (or use left arrow)
C-a  Beginning of line
C-e  End of line
M-f  Forward word
M-b  Backward word

Delete, cut and paste within a line

BACKSPACE Delete character before cursor
C-h  Delete character before cursor
C-d  Delete character under cursor

M-d  Delete word, append to inline paste buffer
C-k  When typed within line, Delete to end of line,
     append to inline paste buffer
C-u  Delete to beginning of line, append ...

C-y  When typed within line, Paste ('yank') 
     from inline paste buffer

Define region

C-@  Set mark that defines one end of region.
     Line at cursor is the other end.
     
Delete, cut and paste multiple lines

C-k  When typed at start of line: Delete line
     and append to multiline paste buffer.
C-w  Delete all lines in region and
     fill (overwrite) multiline paste buffer.

C-y  When typed at beginning of line, Paste
     (yank) lines from multiline paste buffer.

Formatting

M-q  Fill (wrap) lines in region
M-^  Join lines in region into one
C-c >  Indent region
C-c <  Outdent region

Refresh

C-l  Refresh current editing window
M-l  Refresh both editing windows
M-m  Refresh viewer window
     works when cursor in editor window
           
Python

C-x C-r  Write module to file and reload

M-x  Move cursor from window to REPL
pm() Move cursor from REPL to window

M-y  Enter and run a single Python command 
     then return to window
