
                Piety Keys
                ==========
                    
This is a complete list of all the key
sequences (usually just called keys) used in
the Piety desktop and Piety editors.

C-v, control v, means hold down the CTRL key
     and press the v key.
     
M-v, meta v, means hold down the ALT key and 
     press the v key.

Moving through a buffer

C-v  Scroll down half a page
M-v  Scroll up half a page
M-<  Move to the top of the buffer
M->  Move to the bottom of the buffer 
C-n  next line, move down one line
     (or use the down arrow key)
C-p  previous line, move up one line
     (or use the up arrow key)
     
Buffer, choose buffer from the list

C-x C-b   Show buffer list, go to line, then:
 ENTER     Show buffer in the viewer window
 M-ENTER   Show buffer in an editor window
 
Buffer, enter buffer name at the prompt

C-x b   Show 'Switch to ...' prompt, then:
 ENTER  Default, return to previous buffer 
 fname ENTER  Show buffer named 'fname'
 fn? ENTER  Show buffer whose name starts 'fn'
 ??? ENTER  Cancel, leave buffer unchanged
